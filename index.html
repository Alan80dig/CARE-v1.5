🚀 Быстрый старт

Требования: Windows 10/11 (64-bit), PowerShell 5.1+, права администратора

# 1. Скачай файл CARE-v1.5.ps1
# 2. Нажми правой кнопкой → "Запустить с помощью PowerShell"
# 3. Или через консоль администратора:
powershell -ExecutionPolicy Bypass -File "C:\Tools\CARE\CARE-v1.5.ps1"

⚠️ Важное замечание по безопасности

Скрипт предназначен для личных компьютеров. На корпоративных машинах:

  • Согласуйте запуск с IT-отделом
  • Соблюдайте политику информационной безопасности
  • Автор не несёт ответственности за использование в корпоративной среде
